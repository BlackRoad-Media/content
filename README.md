# content

Marketing content and media resources

## 🚦 Traffic Light System

This repository uses the **BlackRoad Codex** traffic light system for managing issues, PRs, and project status:

- **🟢 GreenLight:** Ready to proceed (approved, tested, validated)
- **🟡 YellowLight:** Needs review or has concerns
- **🔴 RedLight:** Critical issues or blockers (DO NOT MERGE)

See [BlackRoad Codex](.github/BLACKROAD_CODEX.md) for complete documentation.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/BlackRoad-Media/content.git
cd content

# Explore the templates
ls -la .github/ISSUE_TEMPLATE/
ls -la .github/workflows/
```

## 📋 Issue Templates

We provide three main issue templates:

1. **🟢 GreenLight** - For items ready to proceed
2. **🟡 YellowLight** - For items needing review
3. **🔴 RedLight** - For critical issues

[Create a new issue](../../issues/new/choose) to get started!

## 🔄 Pull Request Template

Our PR template includes:
- Traffic light status indicators
- Comprehensive checklists
- BlackRoad Codex compliance checks

## 🤖 Automated Workflows

Three CI/CD workflows monitor traffic light status:
- **GreenLight CI:** Validates readiness
- **YellowLight CI:** Requires additional reviews
- **RedLight CI:** Blocks merging for critical issues
